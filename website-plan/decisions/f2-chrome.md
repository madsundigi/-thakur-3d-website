# f2-chrome — decision log (Wave 1: layout chrome, booking glue, brand assets)

Branch `wave1/f2-chrome`. Scope: `Base.astro`, the chrome components (Header, StickyBar, WaFloat, Footer, Nap, Button,
PromiseBand, Logo, ExitCard, icons), the booking widget glue (`src/lib/{analytics,booking,leads,whatsapp,ref,schedule,validate,format}.ts`),
`/book/`, `/thank-you/`, 404, robots, `astro.config.mjs`, `public/**` and `scripts/make-assets.mjs`.

Rule order applied: `02` [Launch-blocker] > page blueprint > `00` §11 > `06`/`07`/`08`/`04`/`09`. Decisions already taken
and implemented as given: **D1** (exit nudge = non-modal corner card), **D4** (consent line links the privacy policy;
reminders/offers only after a YES reply), **E7** (sitemap = live routes + real lastmod; noindex = "noindex, follow"),
**E9** (NAP = `05` §4 verbatim), **E10** (GA4 area params: no digits, ≤ 30 chars).
