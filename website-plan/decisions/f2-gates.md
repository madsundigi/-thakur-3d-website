One line each: **what** — why — *doc that lost* (rule order: 02 [Launch-blocker] > page blueprint > 00 §11 > 06/07/08/04/09).

1. **Blueprint equality codes: title → P012, meta → P020, H1 → P026** — 02 has no parameter for "copy = blueprint"; these are the keyword-placement rules the blueprint wording is written to satisfy — *none*.

6. **04 §2.9 matrix hard-coded in `scripts/lib/plan.mjs`; `/offers/` requires OfferCatalog, `/join-as-groomer/` JobPosting optional; a page with no row WARNs; missing BreadcrumbList → P084, LocalBusiness → P078, Service → P082, anything else → P077** — the matrix is binding and `schema.ts` always emits the /offers/ catalog — *none*.

8. **`[FILL:*]` hrefs are skipped by the link checks and counted in one summary line** — 00 §8 lets pages build with tokens; `check:fill` is their launch gate — *none*.
9. **Booking island = every chunk reachable from `/book/` (static + dynamic imports), gzip -9 of the concatenation ≤ 92,160 B** — 08 §8.1/§8.3 working budget and method; 04 §5.3's 100 KB stays the hard cap named in the message — *04 §5.3 (ceiling only)*.
